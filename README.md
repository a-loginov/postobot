# ПостоБот

Telegram-бот для отправки школьных заявок на замену или ремонт оборудования.

Ученик может создать заявку с описанием проблемы и фотографией, отслеживать её статус.
Администраторы получают уведомления о новых заявках и могут менять их статус.

## Что такое ПостоБот

ПостоБот — это бот, который принимает от учеников заявки на замену или ремонт
оборудования, сохраняет их в базе данных, уведомляет ответственных сотрудников
и позволяет отслеживать статус каждой заявки.

## Требования

- Python 3.12+
- Telegram-аккаунт и свой бот (см. ниже как получить токен)

## Установка Python

Скачайте и установите Python 3.12 или новее с официального сайта:
https://www.python.org/downloads/

Проверьте установку:

```bash
python3 --version
```

## Создание virtual environment

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Создание .env

Скопируйте пример конфигурации:

```bash
cp .env.example .env
```

## Получение BOT_TOKEN

1. Откройте Telegram.
2. Найдите бота [@BotFather](https://t.me/BotFather).
3. Отправьте команду `/newbot`.
4. Следуйте инструкциям, чтобы назвать бота.
5. BotFather пришлёт токен вида `123456789:AAE...`.
6. Вставьте токен в файл `.env`:

```
BOT_TOKEN=123456789:AAE...
```

## Добавление ADMIN_IDS

Telegram ID администраторов указываются через запятую в файле `.env`:

```
ADMIN_IDS=123456789,987654321
```

Чтобы узнать свой Telegram ID, напишите боту [@userinfobot](https://t.me/userinfobot)
в Telegram — он покажет ваш ID.

## Запуск

```bash
pytest
```

## Где находится локальная БД

Локальная SQLite-база данных создаётся автоматически при первом запуске
и хранится в директории:

```
local_db/postobot.db
```

Директория `local_db/` не попадает в Git и предназначена только для
разработки и тестирования.

## Как очистить тестовую БД

Удалите файл базы данных:

macOS/Linux:

```bash
rm -f local_db/postobot.db
```

Windows:

```powershell
del local_db\postobot.db
```

При следующем запуске база данных будет создана заново.
